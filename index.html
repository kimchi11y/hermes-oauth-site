Hermes Agent

Personal automation assistant — single-user, private use

What this application does

Hermes Agent is a locally-run personal assistant used by its owner to automate everyday digital tasks. With the owner's explicit permission, it connects to the owner's own Google Workspace account so the owner can read and act on their own information through a single chat interface, instead of switching between apps.

Through the Google APIs, the application can:

  • Gmail — search and read the owner's messages, and send or reply to email on the owner's behalf when asked.
  • Google Calendar — list upcoming events and create or delete calendar events on request.
  • Google Drive — search, upload, download and organise files in the owner's own Drive.
  • Google Contacts — look up contact names, email addresses and phone numbers (read-only).
  • Google Sheets — read and write spreadsheet content the owner requests.
  • Google Docs — read and create documents at the owner's request.

Who uses it

This is not a public product and has no user base. It is a personal tool running on one individual's own computer, operating exclusively on that same individual's Google account. No other person's data is accessed, and no account holders are onboarded.

How data is handled

Google account data is accessed live, only at the moment the owner makes a request, and is stored on the owner's own device. It is never transmitted to the application's author, sold, or shared with any third party. See the Privacy Policy for full detail.
