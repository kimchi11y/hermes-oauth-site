Privacy Policy

Hermes Agent — last updated 29 September 2026

This policy explains how Hermes Agent ("the application") accesses, uses, stores and protects information from Google accounts. The application is a personal-use tool operated by a single individual on their own computer, and it accesses only that individual's own Google account.

1. Information accessed

With the account holder's explicit authorisation via Google OAuth 2.0, the application may access:

Google serviceWhat is accessedWhy
GmailMessage search, message content, labels; sending and replyingTo let the owner find, read, send and reply to their own email on request
Google CalendarEvent titles, times, locations, attendees, descriptionsTo show upcoming events and create or remove events the owner asks for
Google DriveFile and folder names, metadata, file contentsTo search, upload, download and organise the owner's own files
Google ContactsNames, email addresses, phone numbers — read-onlyTo look up contact details the owner asks for
Google SheetsCell values in spreadsheets the owner specifiesTo read and update spreadsheet content on request
Google DocsDocument text in documents the owner specifiesTo read and create documents on request

Access is limited to the account holder's own data. The application does not access the data of any other Google user, and it requests no scopes beyond those listed above.

2. How information is used

Information is used for one purpose only: carrying out the task the account holder has requested (for example, "show my unread email" or "add this event to my calendar"). The application performs no analytics, profiling, advertising, marketing, or automated decision-making, and it does not build any profile of the account holder.

3. Storage and retention

Data is processed live, in memory, at the moment of a request. It is not copied into any external database or cloud service operated by the application.

  • OAuth credentials — the access and refresh tokens issued by Google are stored in a file on the account holder's own computer, protected by that computer's operating-system file permissions.
  • Session history — records of past requests may be kept locally on the same device so the assistant can maintain context. These stay on the device and are never uploaded.
  • Retention — local history is retained only as long as the account holder chooses, and can be deleted at any time by that individual.

4. Sharing and disclosure

Information obtained from Google is never sold, rented, traded or shared with any third party. It is not used for advertising, and it is not used to train machine-learning models. No third-party service receives Google account data from this application.

Where a language model is used to interpret a request, only the minimum text needed for that request is involved, and Google account data is never provided to model providers for training purposes.

5. Security

OAuth 2.0 is used for all Google access, so the account holder's Google password is never seen or stored by the application. Tokens are held locally and transmitted only over encrypted HTTPS connections to Google's own API endpoints. Access can be revoked by the account holder at any time (see section 6).

6. Revoking access and deleting data

The account holder can withdraw access at any time, without involving the application author:

  • Visit myaccount.google.com/permissions and remove Hermes Agent's access. This immediately invalidates the stored tokens.
  • Delete the local credential file and any local history from the device.

7. Limited Use disclosure

Hermes Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google account data is used only to provide the user-facing features described in section 1, is not transferred to third parties except as necessary to provide those features or as required by law, and is never used for advertising or to train machine-learning models.

8. Children's privacy

The application is not directed at children and is not offered to the public. It is used solely by its adult owner on their own account.

9. Changes to this policy

Any changes will be published on this page with an updated revision date. Continued use of the application after a change constitutes acceptance of the revised policy.
